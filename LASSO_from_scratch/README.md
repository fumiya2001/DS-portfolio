 # LASSO Regression from Scratch (R)

## Overview
This project implements the LASSO (Least Absolute Shrinkage and Selection Operator) regression algorithm from scratch using **R**, without relying on external libraries. 

## Key Features
- **Comparison of Algorithms**: Implemented and compared two major optimization methods:
    1. **Coordinate Descent (CDA)**
    2. **ADMM (Alternating Direction Method of Multipliers)**
- **Practical Application**: Validated using the **Boston Housing Dataset**, comparing results with the Least Squares Method (LSE).
